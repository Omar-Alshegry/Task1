Library Management System (Task 1 Adv);

A simple library management system built using TypeScript, HTML, and CSS only, to apply Object-Oriented Programming (OOP) concepts without using any external libraries.


About The Project:

This project aims to simulate an electronic library management system, allowing the user to:
- Display a list of books as cards.
- Search for books by title or author.
- Filter books by category.
- Toggle book availability status (Available / Not Available).
- Delete books from the library.

This project was designed to apply the core concepts of OOP:
1- Encapsulation
2- Inheritance
3- Polymorphism
4- Abstraction

Built With:

- HTML5: For building the basic structure of the page.
- CSS3: For styling the interface and making it simple and clear (without Bootstrap or any external libraries).
- TypeScript: For writing the programming logic and applying OOP concepts.
- JavaScript (ES6): The final output after compiling the TypeScript code.
